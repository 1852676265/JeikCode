# 开机自启与远程访问

JeikCode 支持在任意物理机、云服务器或软路由网关上作为全天候后台服务运行。无论你身处何地，都可以通过浏览器、手机、平板或其他终端设备随时接入，实现高效的远程项目管理与 AI 协同编程。

---

## 一、跨平台通用 CLI 开机自启

目前配置开机自启推荐且跨平台通用的方式是**通过命令行 CLI 一键配置**。该机制全面兼容 **Windows、Linux、macOS、OpenWrt / iStoreOS** 等跨平台设备。

### 1. 统一配置命令

在终端中统一输入以下命令（可按需指定主机地址、端口与鉴权 Token）：

::: code-group

```bash [监听所有网卡 (推荐远程访问)]
# 允许局域网或公网跨设备远程访问
jeikcode --host 0.0.0.0 --port 13457 --token your-secure-token
```

```bash [仅监听本地回环]
# 仅供本机浏览器访问
jeikcode --host 127.0.0.1 --port 13457 --token your-secure-token
```

:::

> 🔒 **安全守则**：为了杜绝服务暴露后遭受未授权访问或恶意扫描，**绑定非本地回环地址（如 `0.0.0.0`）时强制要求配置 `--token` 或环境变量 `JEIKCODE_SERVER_TOKEN`**，拒绝无密码裸奔启动。

### 2. 全自动系统特征适配

执行上述命令后，JeikCode 命令行会**自动检测并分析你当前系统的环境特征**，并弹出交互向导为你一键注册开机自启：

- **Linux 发行版**（Ubuntu、Debian、CentOS、Arch 等）：自动对接并注册为标准 `systemd` 系统服务；
- **macOS**：自动生成并在用户层注册 `launchd` 守护配置；
- **OpenWrt / iStoreOS**（软路由与嵌入式网关）：自动识别嵌入式环境，对接 OpenWrt 原生轻量级 `procd` 进程管理器，并注入进程崩溃自动拉起机制；
- **Windows**：自动注册系统后台服务与开机启动任务。

你无需手动编写复杂的 `.service` 配置文件或守护脚本，跟随终端提示即可秒级完成开机自启常驻。

### 3. 一键访问 WebUI 进行远程管理

后台服务启动并注册成功后，终端会即时输出带有安全 Token 的访问链接，例如：

```text
============================================================
JeikCode Daemon 服务已就绪！
WebUI 本地访问地址:   http://127.0.0.1:13457/?token=your-secure-token
局域网远程管理地址:   http://192.168.1.100:13457/?token=your-secure-token
============================================================
```

在同一局域网（或通过内网穿透 / VPN）的手机、平板或便携本浏览器中打开该远程管理链接，即可无缝进入完整的 WebUI 界面，享受与本地客户端完全一致的会话交互、代码图谱全景检索、文件管理与多模型调度。

> 📌 **Windows 特别说明**：  
> Windows 桌面版目前尚未开发图形界面的开机自启开关，因此在 Windows 环境下，同样**统一通过上述命令行 CLI 一键配置后台 Daemon 开机自启服务**。

## 二、桌面端天生具备远程协同服务

如果你在日常 PC 或 Mac 上使用 **JeikCode 桌面客户端 (Desktop)**，甚至无需使用命令行配置：

- **天生自带后台监听**：桌面客户端只要双击打开，**后台默认天生就会自动启动一个监听在 `0.0.0.0`、并带有随机高强度安全 Token 的后台 Daemon 服务**；
- **免繁琐配置**：只要电脑上的桌面端处于运行状态，局域网内的其他设备（如你的手机或平板）即可直接通过电脑的 IP 地址与桌面端生成的 Token 访问 WebUI；
- **多端实时联动**：在手机浏览器上发送的提问与生成代码，电脑桌面端界面实时双向同步，实现真正的多端无缝漫游开发。

## 三、后台服务管理与维护

JeikCode 提供了极简的跨平台服务生命周期管理命令：

```bash
# 列出当前系统中已安装的所有 JeikCode 后台自启服务
jeikcode server list

# 卸载并注销指定的后台服务（自动停止进程、移除自启项并清理系统脚本）
jeikcode server uninstall <服务ID>
```
